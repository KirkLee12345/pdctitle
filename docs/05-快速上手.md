# 05 · 快速上手（一页搞懂 PDCTitle）

> 只想先把它跑起来？看完这一页就够。完整参数、配置格式与设计细节见 `docs/02-指令与配置参考.md`、`docs/01-需求与设计方案.md`。

## 一句话

纯服务端模组：**OP 建称号池 → 授权给玩家 → 玩家自己点一下佩戴**，称号随即出现在他名字前面（聊天栏、头顶名牌）。
玩家端**不用装任何东西**，原版客户端即可看到。

## 先记住 3 个概念

| 概念 | 谁来做 | 说明 |
|---|---|---|
| **称号池**（定义） | OP | 全服共用的称号模板：id + 显示文案 + 描述。例如 `legend` → `&b[至尊]` |
| **授权**（归属） | OP | 把池里的某个称号发给某（些）玩家，可发给很多人 |
| **佩戴** | 玩家自己 | 玩家在已获授权的称号里选一个戴上（0 个或 1 个） |

称号是**按 UUID 记账**的：玩家改名不掉授权；OP 删掉池里的定义，所有人的这个称号一起消失。

## 三步跑通

### 第 1 步：装到服务器

1. 服务器须为 Fabric 专用服务器：Minecraft **26.2**、Fabric Loader **≥ 0.19.3**、Java 25；
2. 把 `pdctitle-1.0.0.jar` 丢进服务器 `mods/` 目录；
3. 重启服务器。首次启动自动生成 `config/pdctitle/config.json`。

### 第 2 步：OP 建称号并授权

```
/pdctitle add legend "&b[至尊]" 开服最早一批元老玩家的纪念称号
/pdctitle grant KirkLee123 legend      # 发给一个人
/pdctitle grant @a legend              # 发给全体在线玩家（支持选择器批量）
```

### 第 3 步：玩家自己佩戴

```
/plt my
```

聊天栏会弹出一份可点击的菜单：**点某个称号就立刻戴上/切换**，点末尾灰色的 `[不佩戴称号]` 卸下。
也支持命令行：`/plt wear legend`、`/plt wear none`。

完成后聊天栏就是：

```
[至尊] <KirkLee123> 大家好
   ↑ 鼠标悬停在“至尊”上可以看到 OP 写的描述
```

## 指令速查

根指令 `/pdctitle`，等价简写 **`/plt`**（原版已占用 `/title`，所以不用它）。

| 分类 | 指令 | 作用 |
|---|---|---|
| **① 称号池**<br>（OP） | `/pdctitle add <id> "显示文案" [描述...]` | 新建称号；文案含 `&` `[]` 空格时必须用英文双引号 |
| | `/pdctitle edit <id> 新文案` | 改显示文案（全服即时生效） |
| | `/pdctitle desc <id> 描述` | 设置描述（`none` 清空），支持 `&` 颜色码 |
| | `/pdctitle remove <id>` | 删除称号 → 所有玩家的该称号级联消失 |
| | `/pdctitle list` / `info <id>` / `who <id>` | 看全部 / 看详情 / 看谁拥有 |
| **② 归属**<br>（OP） | `/pdctitle grant <目标> <id>` | 授权（可批量，重复自动跳过） |
| | `/pdctitle set <目标> <id>` | 授权 + 立即给他戴上 |
| | `/pdctitle revoke <目标> <id>` | 收回（正戴着会自动卸下） |
| | `/pdctitle clear <目标>` | 清空该玩家全部称号 |
| **③ 玩家**<br>（人人可用） | `/plt my` | 聊天菜单：点击佩戴/切换，`[不佩戴称号]` 卸下 |
| | `/plt wear <id>` / `wear none` / `unwear` | 命令行佩戴 / 卸下 |
| **通用** | `/pdctitle reload` | 重载配置与数据（OP） |

**`<目标>` 支持原版选择器**：`@a`（全部在线）、`@p`、`@r`、`@s`、`@e[type=player,...]`，也可以直接写玩家名（含离线玩家，走本地名字索引）或 UUID。

## 最容易踩的坑：引号

| 参数 | 规则 |
|---|---|
| `<id>` | 只能小写字母/数字/`_`/`-`，1–32 字符；写错会直接报错 |
| **显示文案**（`add` 里） | 含 `&`、`[]`、中文、空格的**必须**用英文双引号包住：`"&b[至尊]"`；纯字母数字可不加 |
| **描述**（`add` 尾部 / `desc`） | 整行随便写，`&` 码、中文、空格都直接写，**不要**加引号 |

带颜色码的写法（`&` 后跟颜色/格式字母，和原版告示牌一个套路）：

```
&b 青色   &e 黄色   &c 红色   &a 绿色   &l 加粗   &o 斜体   &r 重置
/pdctitle add vip "&e[&6VIP&e]" 充值玩家专属
/pdctitle desc vip &6金色传说：本服充值排行榜前十
```

## 显示在哪里 / 怎么关

| 通道 | 默认 | 效果 |
|---|---|---|
| 聊天栏 | 开 | `[称号] <名字> 消息`，悬停称号显示描述 |
| 头顶名牌 | 开 | 名字前面带称号，靠原版队伍前缀同步，所有客户端可见 |
| Tab 列表 | **关** | 为避免与其它 Tab 管理模组打架，默认不开 |

改 `config/pdctitle/config.json` 后执行 `/plt reload`（或重启）：

```json
{ "chat": true, "tab": false, "nametag": true }
```

## 常见问题

- **玩家说“我没有称号”** → 他没被授权，或没佩戴。让他 `/plt my` 看一眼；OP 用 `/pdctitle who <id>` 查归属。
- **报错 / 命令不识别** → 显示文案里的特殊字符没加双引号，或者用了 `/pdc`（不存在，简写是 `/plt`）。
- **Tab 栏没变化** → 默认关闭，属正常；需要就去 `config.json` 打开。
- **聊天里没有 `[Not Secure]` 标记** → 第三方验证/离线服的消息本就未签名，模组按未签名路径重发，服务端日志仍是原版格式。
- **想批量发** → `/pdctitle grant @a <id>`；按队伍/标签筛选用 `@a[team=xxx]`。
- **改文案要不要重发** → 不用，`edit`/`desc` 全服即时生效，下次发言/刷新即见。
