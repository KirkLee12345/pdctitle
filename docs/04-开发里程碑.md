## 测试矩阵（M4 验收）

| 场景 | 期望 |
|---|---|
| 原版客户端看到称号（无任何客户端 mod） | 聊天/Tab/头顶三处显示 |
| 玩家未获授权 | 一切与原版一致，不拦截聊天 |
| grant 后未 wear | 拥有但不显示；wear 后三处出现 |
| wear none / unwear | 三处恢复原名 |
| 池条目 edit（改文案） | 所有佩戴者即时变化 |
| 池条目 remove | 所有玩家该称号消失，佩戴中自动卸下 |
| 同一称号授权给多名玩家 | 各自佩戴互不串号 |
| 聊天栏鼠标悬停称号 | 显示 称号名+描述；无描述只显称号名 |
| 离线 grant → 重进 | 自动生效 |
| 名称含 & 码/中文 | 正确着色与显示 |
| 注入文本（换行/控制符） | 被清洗，安全 |
