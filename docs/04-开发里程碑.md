## 测试矩阵（M4 验收）

| 场景 | 期望 |
|---|---|
| 原版客户端看到称号（无需任何客户端 mod） | 三处均显示 |
| 玩家拥有 0 个称号 | 一切与原版一致，不拦截聊天 |
| grant 后未 wear | 拥有但不显示；wear 后三处出现 |
| wear none / unwear | 三处恢复原名 |
| revoke 佩戴中的称号 | 自动卸下，三处恢复原名 |
| 离线 grant → 重进 | 自动生效 |
| 两名玩家互换佩戴 | 各自正确，互不串号 |
| 聊天消息不被注入/换行截断 | 显示安全 |
