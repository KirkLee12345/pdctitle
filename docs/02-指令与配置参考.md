# 02 · 指令与配置参考（v3：称号池）

> 想要一页看懂怎么用？先看 [`05-快速上手.md`](05-快速上手.md)；本文是完整参数与配置参考。

根指令 `/pdctitle`（另有别名 `/plt`），分三级；**单独输入 `/plt` 等同 `/plt my`**。不使用 `/title`——它与原版“屏幕标题”指令冲突。**池/归属管理区**需 OP；**玩家自助区**人人可用。

## 1. 称号池管理（OP）

| 指令 | 说明 | 示例 |
|---|---|---|
| `/pdctitle add <id> <显示文案> [描述...]` | 新增称号定义；显示文案后可直接用空格跟描述（可选） | `/pdctitle add legend "&b[至尊]" 开服元老纪念称号` |
| `/pdctitle edit <id> <显示文案...>` | 修改显示文案（所有已授权玩家即时生效） | `/pdctitle edit legend &b[至高无上]` |
| `/pdctitle desc <id> <描述...>` | 设置描述；参数为 `none` 则清空 | `/pdctitle desc legend 开服元老纪念` |
| `/pdctitle remove <id>` | **删除定义 → 所有玩家该称号级联消失**（佩戴中自动卸下） | `/pdctitle remove legend` |
| `/pdctitle list` | 列出全部称号（id/文案/描述/拥有者数） | `/pdctitle list` |
| `/pdctitle info <id>` | 查看单条定义详情 | `/pdctitle info legend` |
| `/pdctitle who <id>` | 查看哪些玩家拥有该称号（在线者高亮） | `/pdctitle who legend` |

- `<id>`：`^[a-z0-9][a-z0-9_-]{0,31}$`，提供自动补全；
- **显示文案**（`add` 中为普通参数，受 Brigadier 字符白名单限制）：含 `&`、`[]`、中文或空格时请用**英文双引号**包裹，如 `"&b[至尊]"`；纯字母数字可省略引号；
- **描述**：整行参数，任意字符（含 `&` 颜色/格式码）均可直接书写，无需引号；
- `edit` / `desc` 的文案与描述均为整行参数，`&`、中文等直接写即可。

## 2. 归属管理（OP）

| 指令 | 说明 | 示例 |
|---|---|---|
| `/pdctitle grant <目标> <id>` | 授权池中称号（支持批量；重复授权自动跳过） | `/pdctitle grant @a legend` |
| `/pdctitle set <目标> <id>` | 授权 + 立即佩戴（支持批量） | `/pdctitle set @a legend` |
| `/pdctitle revoke <目标> <id>` | 收回授权（若正佩戴自动卸下） | `/pdctitle revoke @a legend` |
| `/pdctitle clear <目标>` | 清空目标玩家全部授权并卸下 | `/pdctitle clear @a` |
| `/pdctitle unequip <目标>` | **只卸下佩戴中的称号**，授权与池中定义都保留（可再 `set`/`wear` 戴回） | `/pdctitle unequip @a` |

**`<目标>` 支持原版选择器与玩家名**：
- 选择器：`@a`（全部在线）、`@p`（最近）、`@r`（随机一名）、`@s`（自己）、`@e[type=player,...]`（可带参数）；
- 玩家名：在线玩家直接写名字、UUID 均可；**离线玩家、甚至本模组从没记录过的玩家**也能解析——顺序为：在线 → 模组本地名字记录 → 服务器玩家数据（进过服/被管理过的名字，在线模式）｜离线模式则按名字直接推导离线 UUID（与登录时一致）；解析结果会写回模组记录，`who` 里显示可读名字；
- 批量执行：一次指令对选择器匹配到的所有玩家生效，反馈显示处理人数；
- 选择器需执行者具备相应权限（OP）；控制台视为 OP。

## 3. 玩家自助

| 指令 | 说明 | 示例 |
|---|---|---|
| `/pdctitle my`（或直接 `/plt`） | **聊天菜单**：提示语 + 称号列表；点击称号立即佩戴/切换，点灰色 `[不佩戴称号]` 卸下 | `/plt` |
| `/pdctitle wear <id>` | 命令行佩戴自己拥有的称号 | `/pdctitle wear legend` |
| `/pdctitle wear none` / `/pdctitle unwear` | 命令行卸下（显示原名） | `/pdctitle wear none` |

## 3.1 全局显示开关（OP）

| 指令 | 说明 |
|---|---|
| `/plt off` | **关闭所有称号显示**：聊天栏、头顶名牌、Tab 全部回归原版（玩家名干净），适合活动临时占用名字；称号的创建/修改/授权/收回/卸下/查询**全部照常工作**，数据照常保存，只是不显示 |
| `/plt on` | 恢复显示（佩戴中的称号立即回来） |

- 开关持久化在 `config.json` 的 `display` 字段，重启后保持；
- 关闭期间玩家执行 `/plt my`、`/plt wear`、`/plt unwear` 等佩戴相关指令时，反馈末尾会多一句“管理员已关闭称号显示”的提示；
- 关闭期间聊天完全走原版路径，服务端日志也与原版一致。

## 4. 悬停描述行为（聊天栏）

- 玩家发言时（佩戴中），聊天行显示为 `[称号] <玩家名> 消息内容`（称号在尖括号外）；
- **鼠标移到称号文案上** → 显示两行提示：第一行称号显示文案（按 & 码着色），第二行描述（描述含 & 码时按码着色；无码时灰斜体），样式仿成就/进度提示；
- 无描述时仅显示称号文案行；
- 悬停同样作用于 `/pdctitle my`、`list`、`info` 等指令反馈里的称号。

## 5. 配置文件

路径 `config/pdctitle/`（自动创建）：

```jsonc
// definitions.json —— 称号池（OP 用指令维护，也可直接编辑，重载/重启生效）
{
  "legend":  { "display": "&b[至尊]",    "description": "开服元老纪念称号" },
  "founder": { "display": "&a[创世元老]", "description": "建设服务器的功臣" }
}
```

```jsonc
// players.json —— 玩家归属与佩戴
{
  "a1b2c3d4-...": { "owned": ["legend", "founder"], "equipped": "founder" }
}
```

约束：`equipped ∈ owned`；owned 只含存在的池 id（加载时自动清理脏数据）；两个文件均原子写盘。

另有全局通道开关 `config.json`（自动创建），默认值如下——Tab 默认关闭以便与其它管理 Tab 的模组共存：

```json
{ "display": true, "chat": true, "tab": false, "nametag": true }
```

`display` 是全局显示总开关（见 3.1），一般用 `/plt on` / `/plt off` 改；三个通道开关只在 `display=true` 时生效。

## 6. 常用操作示例

```
# OP：先建池（显示文案含 & 与 []，用引号包住），描述可直接带上
/pdctitle add legend "&b[至尊]" 开服最早一批元老玩家的纪念称号
/pdctitle desc legend &e改个金黄色描述          # 单独补/改描述（支持 & 码）
/pdctitle grant KirkLee123 legend
/pdctitle grant Alice legend                 # 同一称号可以发给很多人

# 玩家：聊天菜单（点击称号佩戴/切换，点 [不佩戴称号] 卸下）
/plt my
# 或命令行方式
/plt wear legend
/plt wear none

# OP：只把某人佩戴中的称号摘掉（授权保留），或活动期间全服隐藏称号
/pdctitle unequip Alice
/pdctitle unequip @a
/plt off
/plt on

# OP：收回 / 删除定义（删后所有玩家不再有该称号）
/pdctitle revoke Alice legend
/pdctitle remove legend

# 悬停：佩戴后聊天显示 [至尊] <KirkLee123> xxx，鼠标移到称号上即见描述
```
