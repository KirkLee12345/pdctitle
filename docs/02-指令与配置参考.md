# 02 · 指令与配置参考（多称号模型）

## 1. 指令总览

根指令 `/title`。分级：**管理员区（OP，level≥2）** 与 **玩家自助区**。

### 1.1 管理员指令

| 指令 | 说明 | 示例 |
|---|---|---|
| `/title grant <玩家> <称号...>` | 授予一条称号；已有同名称号则提示“已拥有” | `/title grant KirkLee123 &b[至尊]` |
| `/title set <玩家> <称号...>` | **授予 + 立即佩戴**（等价旧版“设置称号”）；玩家已拥有同名称号则仅执行佩戴 | `/title set KirkLee123 &a[创世元老]` |
| `/title revoke <玩家> <称号...>` | 收回一条称号；若该玩家正佩戴它则自动卸下 | `/title revoke KirkLee123 &b[至尊]` |
| `/title clear <玩家>` | 清空该玩家全部称号并卸下 | `/title clear KirkLee123` |
| `/title list [玩家]` | 查看某玩家（省略=全部）的拥有与佩戴情况 | `/title list KirkLee123` |

行为约定：
- 目标玩家**离线也可授予/收回**：按名字经服务端 UserCache 解析为 UUID 存储，下次上线自动生效；
  解析失败时报错并给出操作提示（首版可只支持在线玩家 + 简单离线解析，见 M3）。
- 授予时若装备中（set），会立即对在线目标做三通道刷新。

### 1.2 玩家自助指令（任意玩家，仅限自己的称号）

| 指令 | 说明 | 示例 |
|---|---|---|
| `/title my` | 列出自己拥有的全部称号 + 当前佩戴（带编号） | `/title my` |
| `/title wear <称号...>` | 佩戴自己拥有的称号（原文案精确匹配；带空格的称号用引号） | `/title wear &b[至尊]` |
| `/title wear none` | 卸下（不佩戴任何称号） | `/title wear none` |
| `/title unwear` | 卸下的别名 | `/title unwear` |

UX 约定（防错）：
- `wear` 时未找到匹配 → 把 `my` 的列表结果一起提示，让玩家照着抄；
- `my` 输出形如：`你拥有：① &b[至尊] ② &a[创世元老] ｜ 当前佩戴：&a[创世元老]`
  并把每条做成可点击（run_command 填入对应 wear 指令），服务端文本组件即可实现。

### 1.3 参数解析细节

- `<称号...>` = 命令剩余参数用空格拼回原文（支持中文、空格、`&` 颜色码）；
- 原文先经 `TitleData` 构造校验：去控制字符、长度 ≤ 32、非空；
- `&x` 颜色码在“展示时”统一解析（自己写一个轻量 legacy→样式 转换，仿 CraftBukkit
  `ChatColor.translateAlternateColorCodes` 行为，约 30 行，M2 完成）。

## 2. 配置文件

路径：`config/titlemod/titles.json`（自动创建，无需手写；改动即落盘、原子写）。

```json
{
  "<玩家UUID>": {
    "owned": ["&b[至尊]", "&a[创世元老]"],
    "equipped": "&a[创世元老]"
  }
}
```

字段说明：
- `owned`: string[]，该玩家拥有称号的原文案集合（顺序稳定）；
- `equipped`: string（可选），当前佩戴称号的原文案，须 ∈ owned；缺失/空 = 不佩戴。

服务器级通道总开关（后续版本提供，可暂时硬编码默认全开）：

```jsonc
// config/titlemod/config.json（规划中）
{
  "channels": { "chat": true, "tab": true, "nametag": true }
}
```

## 3. 常用操作示例

```
# OP：给 A 授予并佩戴 [至尊]
/title set A &b[至尊]

# OP：给 A 再加一条 [创世元老]（不改变当前佩戴）
/title grant A &a[创世元老]

# 玩家 A：换成 [创世元老]
/title wear &a[创世元老]

# 玩家 A：不戴了，显示原名
/title wear none

# OP：收回 A 的 [至尊]（若 A 正戴着则自动卸下）
/title revoke A &b[至尊]

# OP：A 全部称号清空
/title clear A

# 任何人：看自己
/title my
```
