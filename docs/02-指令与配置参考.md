# 02 · 指令与配置参考（v3：称号池）

根指令 `/plttitle`（另有别名 `/plt`），分三级。不使用 `/title`——它与原版“屏幕标题”指令冲突。**池/归属管理区**需 OP（level≥2）；**玩家自助区**人人可用。

## 1. 称号池管理（OP）

| 指令 | 说明 | 示例 |
|---|---|---|
| `/plttitle add <id> <显示文案> [描述...]` | 新增称号定义；显示文案后可直接用空格跟描述（可选，省略则留空） | `/plttitle add legend &b[至尊] 开服元老纪念称号` |
| `/plttitle edit <id> <显示文案...>` | 修改显示文案（所有已授权玩家即时生效） | `/plttitle edit legend &b[至高无上]` |
| `/plttitle desc <id> <描述...>` | 设置描述；参数为 `none` 则清空 | `/plttitle desc legend 开服元老纪念` |
| `/plttitle remove <id>` | **删除定义 → 所有玩家该称号级联消失**（佩戴中自动卸下） | `/plttitle remove legend` |
| `/plttitle list [页码]` | 分页列出全部称号（id/文案/描述/拥有者数） | `/plttitle list` |
| `/plttitle info <id>` | 查看单条定义详情 | `/plttitle info legend` |
| `/plttitle who <id>` | 查看哪些玩家拥有该称号（在线者高亮） | `/plttitle who legend` |

- `<id>`：`^[a-z0-9][a-z0-9_-]{0,31}$`，提供自动补全；
- `<显示文案...>` 支持 `&` 颜色码与中文/空格，经校验后存储。

## 2. 归属管理（OP）

| 指令 | 说明 | 示例 |
|---|---|---|
| `/plttitle grant <玩家> <id>` | 授权池中称号（重复授权提示“已拥有”） | `/plttitle grant KirkLee123 legend` |
| `/plttitle set <玩家> <id>` | 授权 + 立即佩戴（快捷） | `/plttitle set KirkLee123 legend` |
| `/plttitle revoke <玩家> <id>` | 收回授权（若正佩戴自动卸下） | `/plttitle revoke KirkLee123 legend` |
| `/plttitle clear <玩家>` | 清空该玩家全部授权并卸下 | `/plttitle clear KirkLee123` |

## 3. 玩家自助

| 指令 | 说明 | 示例 |
|---|---|---|
| `/plttitle my` | 列出自己拥有的称号与佩戴情况；每条可点击快速佩戴 | `/plttitle my` |
| `/plttitle wear <id>` | 佩戴自己拥有的称号 | `/plttitle wear legend` |
| `/plttitle wear`（不带参） | 显示可选列表（避免记不住 id） | `/plttitle wear` |
| `/plttitle wear none` / `/plttitle unwear` | 卸下（显示原名） | `/plttitle wear none` |

## 4. 悬停描述行为（聊天栏）

- 玩家发言时（佩戴中），聊天行发送者为 `[称号显示文案] 玩家名`；
- **鼠标移到称号文案上** → 显示两行提示：称号显示文案（带颜色）+ 描述（灰色斜体），样式仿成就/进度提示；
- 无描述时仅显示称号文案行；
- 悬停只作用于聊天栏称号部分，不影响名字与消息正文。

## 5. 配置文件

路径 `config/plttitle/`（自动创建）：

```jsonc
// definitions.json —— 称号池（OP 用指令维护，也可直接编辑，重载/重启生效）
{
  "legend":  { "display": "&b[至尊]",    "description": "开服元老纪念称号" },
  "founder": { "display": "&a[创世元老]", "description": "建设服务器的功臣" }
}
```

```jsonc
// players.json —— 玩家归属与佩戴
{
  "a1b2c3d4-...": { "owned": ["legend", "founder"], "equipped": "founder" }
}
```

约束：`equipped ∈ owned`；owned 只含存在的池 id（加载时自动清理脏数据）；两个文件均原子写盘。

## 6. 常用操作示例

```
# OP：先建池，再发称号
/plttitle add legend &b[至尊]
/plttitle desc legend 开服最早一批元老玩家的纪念称号
/plttitle grant KirkLee123 legend
/plttitle grant Alice legend          # 同一称号可以发给很多人

# 玩家：佩戴
/plttitle my
/plttitle wear legend

# 玩家：卸下
/plttitle wear none

# OP：收回 / 删除定义（删后所有玩家不再有该称号）
/plttitle revoke Alice legend
/plttitle remove legend

# 悬停：玩家佩戴 legend 后聊天，把鼠标移到聊天栏称号上即见描述
```
